## Description

This PR implements the Statutory Severance and Retrenchment Relief Gating Engine for compliant exit settlements and multi-year Section 89 tax relief calculation.

* **Severance Package Model** (severancePackage.model.js): Records retrenchment packages, tenure tracking, statutory notice periods, Section 10(10C) exemptions, and Section 89 relief amounts.
* **Severance Calculator Service** (severanceCalculator.service.js): Computes 15-day statutory daily rates, notice payouts, statutory exemption ceilings, and marginal tax relief spreads.
* **Severance Controller & Routes** (severance.controller.js, severance.routes.js): Exposes /api/severance/preview, /api/severance/packages, /api/severance/packages/:id/approve, and /api/severance/packages/:id/disburse.
* **Tests & Documentation**: Added unit test suite and comprehensive documentation.
