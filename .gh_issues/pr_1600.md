## Description

This PR implements the Fringe Benefit Tax (FBT) Gross-Up & Valuation Engine for non-cash employee perk compliance and statutory quarterly tax return generation.

* **Fringe Benefit Record Model** (ringeBenefitRecord.model.js): Logs non-cash perks (company cars, housing, concessional loans), net employee contributions, and FBT liabilities.
* **FBT Calculator Service** (btCalculator.service.js): Calculates statutory Type 1 (GST creditable, 2.0802x) and Type 2 (GST-free, 1.8868x) gross-ups and employer tax liabilities.
* **Fringe Benefits Controller & Routes** (ringeBenefits.controller.js, ringeBenefits.routes.js): Exposes /api/fringe-benefits/preview, /api/fringe-benefits/records, and /api/fringe-benefits/quarterly-report.
* **Tests & Documentation**: Added unit test coverage and statutory tax specifications documentation.
