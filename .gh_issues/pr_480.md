## Description

This PR addresses Issue #480 by implementing widespread WCAG 2.1 Compliance fixes across the React frontend.

Through an automated and manual audit of the JSX component tree, several severe accessibility violations were resolved:
- **Missing Alt Text**: Enforced `alt=""` on all decorative `<img>` tags that lacked alt properties to prevent screen readers from reading the raw image source URL.
- **Icon Buttons without ARIA Labels**: Added dynamic `aria-label` tags to generic `<button>` elements that only contain an SVG or Icon component (e.g., `<TrashIcon />`, `<EditIcon />`), ensuring non-sighted users understand the button's action.
- **Anchor tag navigation**: Identified `<a>` tags acting as buttons (using `onClick` handlers without an `href`). These were dynamically patched to include `role="button"` and `tabIndex={0}` to restore keyboard navigation (Tab-targeting) and semantics.

These improvements significantly elevate the application's baseline accessibility score in Lighthouse and ensure compliance for enterprise deployment.
