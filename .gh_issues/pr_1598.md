## Description

This PR implements the Performance Share Units (PSU) and Relative TSR Vesting Valuation Engine for performance-conditioned executive equity compensation.

* **PSU Grant Model** (psuGrant.model.js): Tracks target performance share volumes, peer company benchmark indices, baseline stock prices, and final vesting multipliers.
* **PSU Valuation Service** (psuValuation.service.js): Implements Relative Total Shareholder Return (TSR) calculations, statistical percentile ranking, and non-linear multiplier curves (0.0x to 2.0x).
* **PSU Controller & Routes** (psu.controller.js, psu.routes.js): Exposes /api/psu/grants and /api/psu/grants/:id/evaluate.
* **Tests & Documentation**: Added unit test suite for Relative TSR valuation and mathematical specification documentation.
