## Description

This PR implements the Activity-Based Labor Cost Allocation Ledger to distribute gross compensation, employer tax liabilities, and benefits across project codes proportionally based on timesheet hours.

* **Labor Allocation Rule Model** (laborAllocationRule.model.js): Configures project cost split rules per employee.
* **Labor Cost Journal Model** (laborCostJournal.model.js): Stores activity-based financial vouchers with allocated salary, employer taxes, and benefit line items.
* **Labor Allocation Service** (laborAllocation.service.js): Calculates project timesheet ratios and computes proportional cost distribution.
* **Labor Allocation Controller & Routes** (laborAllocation.controller.js, laborAllocation.routes.js): Exposes /api/labor-allocation/rules, /api/labor-allocation/distribute, and /api/labor-allocation/journal.
* **Tests & Documentation**: Added unit test suite and accounting architecture documentation.
